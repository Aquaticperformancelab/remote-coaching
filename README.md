# Devilrays Remote Coaching

Tracker program latihan (renang, gym, dryland, mobility) dan laporan harian atlet untuk Devilrays Aquatics.

- `index.html` — aplikasinya (jangan diubah kecuali tahu yang dilakukan)
- `config.js` — alamat Supabase dan publishable key (isi di Langkah 4)
- `logo.png` — logo klub
- `supabase/schema.sql` — struktur database + aturan keamanan (dijalankan sekali di Supabase SQL Editor)

Panduan lengkap ada di dokumen "Tutorial Setup Tracker Devilrays (GitHub + Supabase)".
